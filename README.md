
# 🌱 Planto

Planto is an iOS plant care application designed to help users organize their plants and manage watering reminders.

## Features
- Add and manage plants
- Set watering reminders
- Receive local notifications
- Track watering progress
- Edit and delete plant reminders
- Dark-themed user interface

## Technologies
- Swift
- SwiftUI
- MVVM Architecture
- UserNotifications

## How to Run
1. Clone the repository.
2. Open `planto.xcodeproj` in Xcode.
3. Select an iPhone simulator or device.
4. Build and run the app.
